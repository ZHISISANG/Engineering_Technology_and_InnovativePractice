| 边界项 | 当前口径 |
| --- | --- |
| batch | 仅一个批次的展商咨询工单 |

## 业务链路

```
咨询接收 → 问题分类 → 政策版本检索 → 转派 → 回复审核
```

矛盾点：一线先用群消息解决、再补填工单，回填时间不等于发生时间；版本判定依赖文件名而非有效期与确认状态；交接只写“已处理”，责任与版本断链。
